OmniShield X Browser Extension (Chrome / Edge / Brave, Manifest V3)

A real, working extension generated from the same intelligence core: ~50,000 declarative-net-request block rules from the bundled ad/tracker feeds plus cosmetic ad hiding on top sites.

  • Download omnishield-x-extension.zip from this site's root (or /extension in the repo) and unzip.
  • Open chrome://extensions → enable Developer mode → Load unpacked → select the folder.
  • Pin the 🛡 icon — the popup shows real per-tab block counts.

Privacy The extension has no servers, no analytics, no accounts. Rules are local.

Account & Security — honest status

  • No accounts / cloud yet — there are no OmniShield servers. When the backend ships it will be announced here with signed updates and this page will grow real login + device management.
  • Local-first by design — DNS history, security scans and policies never leave your device.
  • Encrypted upstream DNS — DoH/DoT to the resolver you choose; the VPN captures and filters all app DNS locally.
  • No certificate interception — ever.
