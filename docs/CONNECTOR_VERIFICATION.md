## Counting and honesty rules

1. **Unique endpoint rule** — the generator deduplicates by `(method, endpoint)`; a second
   name pointing at the same URL is dropped, not counted.
2. **Implemented means executable** — an HTTP connector counts only if it has a parser
   wired to the sync engine; a native connector counts only if a probe actually calls the
   Android API and reports real values.
3. **Credentials are never bundled** — providers that require an API key are listed as
   `FREE WITH RESTRICTIONS (credentials)` and remain `NOT CONFIGURED` at runtime.
4. **Unavailable sources stay unavailable** — official sites without a public machine
   interface (PAGASA, NDRRMC, PHIVOLCS) are listed as `SOURCE UNAVAILABLE`; they are not
   scraped and are not presented as APIs.
5. **No fake green** — `CONNECTED` is written only after a successful HTTP+parse cycle or a
   successful native probe; freshness older than 2× the cache TTL degrades to `DEGRADED`.
6. **Tests** — parsers, the sync state machine and the risk engine are covered by
   `ConnectorPlatformTestSuite` on the JVM; Android-API connectors are exercised by their
   own runtime probe (the UI runs them on demand).
