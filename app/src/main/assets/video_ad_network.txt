# AdShield Pro — video-ad network layer (bundled rule fragment, NOT a full upstream feed)
#
# PURPOSE
#   Block the *ad plumbing* that video players use: ad servers, ad exchanges, VAST/VPAID
#   trackers, video-ad SDKs, SSAI/stitcher vendor APIs and ad verification beacons.
#
# WHAT THIS LIST IS
#   A small, hand-curated list written in ABP syntax. It is NOT an upstream feed and is not
#   presented as one. `@@||host^` lines are explicit allow rules: they exempt a host so that
#   blocking something else on the same family cannot take playback down with it.
#
# WHAT THIS LIST MUST NEVER CONTAIN
#   Any host that delivers the video itself — youtube.com, googlevideo.com, netflix.com,
#   nflxvideo.net, tiktokcdn.com, ttvnw.net, aiv-cdn.net, fbcdn.net, vimeocdn.net and the rest of
#   MediaPlaybackGuard.PROTECTED_DELIVERY_HOSTS. A JVM test fails the build if one appears here,
#   and the engine additionally exempts them at a higher priority than any filter list.
#
# HONEST LIMIT
#   Ads stitched into the same stream as the video (YouTube / TikTok / Meta SSAI) are not separate
#   requests. Nothing in this file can remove them; docs/MEDIA_PLAYBACK.md says so plainly.
