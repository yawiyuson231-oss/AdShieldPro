AETHER — domain intelligence & reputation

Type any hostname. Every point of the score is attributed to a named signal with its evidence. AETHER never blocks on its own: enforcement stays with the deterministic filter rules, and you can always override.

DNS resolution lab — encrypted transports, DNSSEC, caching

Runs the real pipeline: filter → cache → DoH (JSON or RFC 8484 wire) → DNSSEC assessment. If the network is unavailable, it says so instead of inventing an answer.

Firewall AI Advance — behavioural detection

Domain-by-domain filtering cannot see a beacon. This engine analyses timing and naming behaviour: periodic check-ins (C2), DNS tunnelling, request-rate bursts and domain fan-out. It recommends; you decide. Safe default is monitor, never an automatic block.

Threat intelligence feeds

Bundled feeds ship with the app. Online updates are validated before they can replace the active copy: structure check, SHA-256 integrity, and rollback protection against truncated or tampered lists.

Privacy-preserving analytics

These statistics are computed and stored on this device only. Hostnames are kept as salted SHA-256 prefixes, never in the clear, and groups smaller than k are suppressed so a report cannot single out one request.

Backup, recovery & policy sync

Snapshots are hashed with SHA-256 and written before any risky operation. On startup the platform verifies them and falls back to the newest valid snapshot — corrupted configuration never silently wipes your settings.

Android ⇄ Web policy transfer (file-based)

Export a backup from the Android app (Settings → Configuration Backup), import it here to audit every custom rule, then export it again. Same JSON schema both ways; nothing is uploaded.

Browser extension (Chrome / Edge / Brave, Manifest V3)

A real extension built by npm run build:extension from the same intelligence core: static declarative-net-request block rules generated from the bundled ad/tracker feeds, plus cosmetic hiding on top sites. The archive is reproducible — rerunning the builder produces identical bytes.

  • Download omnishield-x-extension.zip from this site's root and unzip it.
  • Open chrome://extensions → enable Developer mode → Load unpacked → select the folder.
  • Pin the 🛡 icon. The popup shows per-tab counts from the browser's own matched-rule events when the browser exposes them (unpacked installs do); otherwise it prints “—” and the reason instead of a zero.

Privacy No servers, no analytics, no accounts. Rules are local files.

The extension cannot filter other apps, and it cannot filter traffic inside other browsers — that is an operating-system limit, not a bug. See Capabilities.
