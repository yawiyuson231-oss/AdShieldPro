#
# WHY THIS FILE EXISTS
# The bundled HaGeZi "Light" feed is size-optimised: it lists many *subdomains*
# (ad.ae.doubleclick.net, b.scorecardresearch.com) but not always the apex
# (doubleclick.net). That leaves apex-level requests unfiltered. This supplement
# closes that gap with well-known advertising / measurement infrastructure only.
#
# SAFETY POLICY
# Every entry below is an advertising, attribution or measurement network.
# No entry is a login, payment, CDN, app-store, OS-update, video-delivery or
# authentication domain. Domains that are known to *carry site functionality*
# (e.g. tag managers, payment SDKs, Google APIs) are deliberately excluded and
# live in the optional "aggressive" supplement instead, which ships disabled.
#
